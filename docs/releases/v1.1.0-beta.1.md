**Adaptive Subtitles for Lampa 1.1.0-beta.1** — a pre-release for testing: an English interface. **Checked by automated tests only,
not on a TV yet.** The stable version stays [1.0.0](https://github.com/emoorpheus/lampa-adaptive-subtitles/releases/tag/v1.0.0).
*Русский текст — ниже.*

### What's new

- **English interface.** The plugin follows the Lampa language (Settings → Interface → Interface language): Russian for Russian,
  English for every other language — settings, values and notifications (for example “Subtitles: HDR — dimmed, 48% (by name)”).
  Lampa reloads itself after the language is changed. All strings are in one table, `src/05_i18n.js`.
- Log messages are in English. HDR detection, dimming, settings and storage keys are the same as in 1.0.0.

### Install

Settings → Extensions → Add Plugin: `https://cdn.jsdelivr.net/gh/emoorpheus/lampa-adaptive-subtitles@v1.1.0-beta.1/dist/adaptive_subs.js`.
The GitHub Pages address keeps serving the stable version. Self-hosted by IP: add `?v=1.1.0-beta.1` to the URL.
Then restart Lampa; the console prints `AdaptiveSubs v1.1.0-beta.1 initialized`.
Back to the stable version: put the Pages address (or `@v1.0.0`) back and restart Lampa. Settings and manual HDR/SDR choices are kept
both ways (same storage keys).

### Please test

With Lampa in English: the section **Adaptive Subtitles** in the settings, English notifications at the start of a video, and
dimming in HDR as before — see [docs/tv-checklist.md](https://github.com/emoorpheus/lampa-adaptive-subtitles/blob/v1.1.0-beta.1/docs/tv-checklist.md).

### Tested

- Unit tests on Node.js 18 and 24: 30 tests. End-to-end tests in the Lampa 3.4.4 web build in Chromium: 28 checks, including the
  English interface with Lampa set to English.
- **Not tested on a TV.**

### Known issues

- Only Russian and English; other Lampa languages get English. Translations are welcome: CONTRIBUTING.md → Translations.
- Embedded subtitles on LG webOS have not been checked separately on a real TV; Android TV and Samsung Tizen have not been reported yet.

Files: `adaptive_subs.js` and `SHA256SUMS` (check with `sha256sum -c SHA256SUMS`). Full list of changes:
[CHANGELOG.md](https://github.com/emoorpheus/lampa-adaptive-subtitles/blob/v1.1.0-beta.1/CHANGELOG.md).

**Адаптивные субтитры для Lampa 1.1.0-beta.1** — предварительный выпуск для проверки: английский интерфейс. **Проверен только
автотестами, на ТВ ещё не проверялся.** Стабильная версия — по-прежнему
[1.0.0](https://github.com/emoorpheus/lampa-adaptive-subtitles/releases/tag/v1.0.0).

### Что нового

- **Английский интерфейс.** Плагин следует языку Lampa (Настройки → Интерфейс → Язык интерфейса): русский — для русского,
  английский — для всех остальных языков: настройки, значения и уведомления (например, “Subtitles: HDR — dimmed, 48% (by name)”).
  После смены языка Lampa перезагружается сама. Все строки — в одной таблице, `src/05_i18n.js`.
- Сообщения журнала — на английском. Определение HDR, затемнение, настройки и ключи хранилища — те же, что в 1.0.0.

### Установка

Настройки → Расширения → Добавить плагин: `https://cdn.jsdelivr.net/gh/emoorpheus/lampa-adaptive-subtitles@v1.1.0-beta.1/dist/adaptive_subs.js`.
Адрес на GitHub Pages по-прежнему отдаёт стабильную версию. Свой сервер по IP: добавьте к адресу `?v=1.1.0-beta.1`.
Затем перезапустите Lampa; в консоли появится строка `AdaptiveSubs v1.1.0-beta.1 initialized`.
Вернуться на стабильную версию: верните адрес Pages (или `@v1.0.0`) и перезапустите Lampa. Настройки и ручные выборы HDR/SDR
сохраняются в обе стороны (те же ключи хранилища).

### Просьба проверить

С Lampa на английском: раздел **Adaptive Subtitles** в настройках, английские уведомления при запуске видео и затемнение в HDR, как раньше, —
см. [docs/tv-checklist.md](https://github.com/emoorpheus/lampa-adaptive-subtitles/blob/v1.1.0-beta.1/docs/tv-checklist.md).

### Проверено

- Модульные тесты на Node.js 18 и 24: 30 тестов. Сквозные тесты в веб-сборке Lampa 3.4.4 в Chromium: 28 проверок, в том числе
  английский интерфейс при Lampa на английском.
- **На ТВ не проверялось.**

### Известные проблемы

- Только русский и английский; для остальных языков Lampa — английский. Переводы приветствуются: CONTRIBUTING.md → Translations.
- Встроенные субтитры на LG webOS отдельно на настоящем ТВ не проверялись; с Android TV и Samsung Tizen отчётов пока нет.

Файлы: `adaptive_subs.js` и `SHA256SUMS` (проверка: `sha256sum -c SHA256SUMS`). Полный список изменений:
