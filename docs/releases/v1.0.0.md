**Adaptive Subtitles for Lampa 1.0.0** — the first public release: subtitles are dimmed in HDR, Dolby Vision and HLG video,
so bright white text does not glare on OLED TVs; SDR video keeps Lampa's normal subtitles. *Русский текст — ниже.*

### Highlights

- HDR detection by priority: your choice → ffprobe of the file (TorrServer `/ffp` or the torrent parser) → HLS `VIDEO-RANGE` → torrent title → file name.
- Dimming by brightness, so colours and ASS styling are kept; separate levels for HDR10, Dolby Vision and HLG.
- LG webOS embedded subtitles: opacity through the TV's media service, the same method Lampa uses.
- HDR/SDR key in the player, remembered per torrent or per show.
- No third-party services; plain ES5 for old TV engines; the interface is in Russian.

### Tested devices

Manual test by the maintainer on 2026-11-01 (internal build 4.0, same code as 1.0.0): **LG OLED65M59LA, webOS 25** — subtitles
dimmed in HDR and Dolby Vision video.

### Install

Settings → Extensions → Add plugin: `https://emoorpheus.github.io/lampa-adaptive-subtitles/adaptive_subs.js`
(pinned: `https://cdn.jsdelivr.net/gh/emoorpheus/lampa-adaptive-subtitles@v1.0.0/dist/adaptive_subs.js`). Self-hosted by IP: add `?v=1.0.0` to the URL.
Then restart Lampa; the settings get the section «Адаптивные субтитры».

### Known issues

- Embedded subtitles on LG webOS have not been checked separately on a real TV.
- Android TV and Samsung Tizen have not been reported yet.

### Upgrading from the internal build 4.0

Version numbers restart at 1.0.0. Settings and manual HDR/SDR choices are kept (same storage keys).

Files: `adaptive_subs.js` and `SHA256SUMS` (check with `sha256sum -c SHA256SUMS`). Full list of changes: [CHANGELOG.md](https://github.com/emoorpheus/lampa-adaptive-subtitles/blob/v1.0.0/CHANGELOG.md).

**Адаптивные субтитры для Lampa 1.0.0** — первый публичный выпуск: субтитры приглушаются в видео HDR, Dolby Vision и HLG,
чтобы яркий белый текст не слепил на OLED-телевизорах; в SDR-видео субтитры обычные, как в Lampa.

### Главное

- Определение HDR по приоритету: ваш выбор → ffprobe файла (TorrServer `/ffp` или парсер раздач) → HLS `VIDEO-RANGE` → название раздачи → имя файла.
- Затемнение яркостью, поэтому цвета и оформление ASS сохраняются; отдельные уровни для HDR10, Dolby Vision и HLG.
- Встроенные субтитры LG webOS: прозрачность через медиасервис телевизора — тем же методом, что и сама Lampa.
- Клавиша HDR/SDR в плеере с запоминанием для раздачи или сериала.
- Без сторонних сервисов; чистый ES5 для старых ТВ; интерфейс на русском.

### Проверенные устройства

Ручная проверка автором 2026-11-01 (внутренняя сборка 4.0, код совпадает с 1.0.0): **LG OLED65M59LA, webOS 25** — субтитры
приглушаются в видео HDR и Dolby Vision.

### Установка

Настройки → Расширения → Добавить плагин: `https://emoorpheus.github.io/lampa-adaptive-subtitles/adaptive_subs.js`
(точная версия: `https://cdn.jsdelivr.net/gh/emoorpheus/lampa-adaptive-subtitles@v1.0.0/dist/adaptive_subs.js`). Свой сервер по IP: добавьте к адресу `?v=1.0.0`.
Затем перезапустите Lampa — в настройках появится раздел «Адаптивные субтитры».

### Известные проблемы

- Встроенные субтитры на LG webOS отдельно на настоящем ТВ не проверялись.
- С Android TV и Samsung Tizen отчётов пока нет.

### Переход с внутренней сборки 4.0

Нумерация версий начинается заново с 1.0.0. Настройки и ручные выборы HDR/SDR сохраняются (те же ключи хранилища).

Файлы: `adaptive_subs.js` и `SHA256SUMS` (проверка: `sha256sum -c SHA256SUMS`). Полный список изменений: [CHANGELOG.md](https://github.com/emoorpheus/lampa-adaptive-subtitles/blob/v1.0.0/CHANGELOG.md).
