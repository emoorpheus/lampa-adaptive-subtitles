**Adaptive Subtitles for Lampa 1.1.0-beta.2** — a pre-release for testing: subtitles are dimmed only when HDR is really shown,
and color keys work on Android TV boxes. **Tested on an Android TV box (Tanix TX9); not tested on an LG OLED TV yet.**
The stable version stays [1.0.0](https://github.com/emoorpheus/lampa-adaptive-subtitles/releases/tag/v1.0.0).
*Русский текст — ниже.*

### What's new

- **Setting “Display”** (Auto / HDR display: dim for HDR / SDR only: do not dim). Dimmed subtitles only look right on a real HDR
  picture. In **Auto** the plugin does not dim if the browser reports a display without HDR or if the built-in player cannot decode
  HDR video (HEVC Main 10, Dolby Vision). On LG webOS and Samsung Tizen, Auto works as in 1.0: the video decides.
  Your manual choice (Mode, HDR/SDR key) always wins. It replaces the experimental option “Respect the display HDR state”.
- **The notification tells why**, for example “Subtitles: SDR — normal (Dolby Vision by name; the player cannot play HDR)”.
- **Fixed on Android TV boxes:** an SDR video named `…DV.HDR…` was dimmed to 48 % on an SDR picture (Tanix TX9), and the HDR/SDR
  color key did nothing because the WebView reports color keys as `ColorF0Red` … `ColorF3Blue` with key code 0.
- For plugin developers: the `adaptive_subs` event gets a `screen` field when HDR video is shown as SDR; `window.AdaptiveSubs.screen()`.

### Install

Settings → Extensions → Add Plugin: `https://cdn.jsdelivr.net/gh/emoorpheus/lampa-adaptive-subtitles@v1.1.0-beta.2/dist/adaptive_subs.js`.
The GitHub Pages address keeps serving the stable version. Self-hosted by IP: add `?v=1.1.0-beta.2` to the URL.
Then restart Lampa; the console prints `[AdaptiveSubs] v1.1.0-beta.2 initialized | display: … | HDR decoder: …`.
Back to the stable version: put the Pages address (or `@v1.0.0`) back and restart Lampa. Settings and manual HDR/SDR choices are kept
both ways (same storage keys).

### Please test

- **LG OLED / any HDR TV:** HDR and Dolby Vision video should still get dimmed subtitles with **Display → Auto**.
- **SDR screens and Android TV boxes:** HDR files should keep normal subtitles, with the reason in the notification.
- Steps: [docs/tv-checklist.md](https://github.com/emoorpheus/lampa-adaptive-subtitles/blob/v1.1.0-beta.2/docs/tv-checklist.md).

### Tested

- Unit tests on Node.js 22 and 24: 32 tests. End-to-end tests in the Lampa 3.4.4 web build in Chromium: 34 checks.
- **Tanix TX9** (Android 11, Lampa Android app 1.12.4, WebView 84), a test plan run over `adb`: the plugin reports
  `display: unknown | HDR decoder: no`; an SDR test video named `…2160p.WEB-DL.DV.HDR.mkv` keeps undimmed SRT and ASS subtitles;
  the red key sent with `adb` switches HDR ↔ SDR; the **Display** item is shown in the settings.
- **Not tested on an LG OLED TV.**

### Known issues

- On the Tanix TX9 the built-in player could not play an HEVC 10-bit HDR10 test file, and torrents were opened in an external
  Android player, where the plugin does not run.
- The plugin cannot see whether a TV or box converts HDR to SDR by itself; then choose **Display → SDR only: do not dim**.
- Embedded subtitles on LG webOS have not been checked separately on a real TV; Samsung Tizen has not been reported yet.

**Адаптивные субтитры для Lampa 1.1.0-beta.2** — предварительный выпуск для проверки: субтитры затемняются, только когда HDR
действительно показывается, и цветные кнопки работают на приставках Android TV. **Проверен на приставке Android TV (Tanix TX9);
на телевизоре LG OLED ещё не проверялся.** Стабильная версия — по-прежнему
[1.0.0](https://github.com/emoorpheus/lampa-adaptive-subtitles/releases/tag/v1.0.0).

### Что нового

- **Настройка «Экран»** («Авто» / «HDR-экран: затемнять HDR» / «Только SDR: не затемнять»). Затемнённые субтитры выглядят правильно
  только на настоящей HDR-картинке. В режиме **«Авто»** плагин не затемняет, если браузер сообщает, что экран без HDR, или если
  встроенный плеер не декодирует HDR-видео (HEVC Main 10, Dolby Vision). На LG webOS и Samsung Tizen «Авто» работает как в 1.0:
  решает видео. Ваш ручной выбор («Режим», клавиша HDR/SDR) всегда главнее. Настройка заменила эксперимент «Учитывать HDR экрана».
- **Уведомление объясняет причину**, например «Субтитры: SDR — обычные (Dolby Vision по названию; плеер не воспроизводит HDR)».
- **Исправлено на приставках Android TV:** SDR-видео с `…DV.HDR…` в имени затемнялось до 48 % на SDR-картинке (Tanix TX9), а цветная
  клавиша HDR/SDR не срабатывала, потому что WebView сообщает цветные кнопки как `ColorF0Red` … `ColorF3Blue` с кодом клавиши 0.
- Для разработчиков плагинов: у события `adaptive_subs` появляется поле `screen`, когда HDR-видео показывается как SDR; `window.AdaptiveSubs.screen()`.

### Установка

Настройки → Расширения → Добавить плагин: `https://cdn.jsdelivr.net/gh/emoorpheus/lampa-adaptive-subtitles@v1.1.0-beta.2/dist/adaptive_subs.js`.
Адрес на GitHub Pages по-прежнему отдаёт стабильную версию. Свой сервер по IP: добавьте к адресу `?v=1.1.0-beta.2`.
Затем перезапустите Lampa; в консоли появится строка `[AdaptiveSubs] v1.1.0-beta.2 initialized | display: … | HDR decoder: …`.
Вернуться на стабильную версию: верните адрес Pages (или `@v1.0.0`) и перезапустите Lampa. Настройки и ручные выборы HDR/SDR
сохраняются в обе стороны (те же ключи хранилища).

### Просьба проверить

- **LG OLED / любой HDR-телевизор:** в видео HDR и Dolby Vision субтитры по-прежнему затемняются при **«Экран → Авто»**.
- **SDR-экраны и приставки Android TV:** у HDR-файлов субтитры остаются обычными, а причина написана в уведомлении.
- Шаги: [docs/tv-checklist.ru.md](https://github.com/emoorpheus/lampa-adaptive-subtitles/blob/v1.1.0-beta.2/docs/tv-checklist.ru.md).

### Проверено

- Модульные тесты на Node.js 22 и 24: 32 теста. Сквозные тесты в веб-сборке Lampa 3.4.4 в Chromium: 34 проверки.
- **Tanix TX9** (Android 11, Android-приложение Lampa 1.12.4, WebView 84), план проверок через `adb`: плагин сообщает
  `display: unknown | HDR decoder: no`; тестовое SDR-видео с именем `…2160p.WEB-DL.DV.HDR.mkv` оставляет субтитры SRT и ASS

- Плагин не видит, переводят ли телевизор или приставка HDR в SDR сами; тогда выберите **«Экран → Только SDR: не затемнять»**.
- Встроенные субтитры на LG webOS отдельно на настоящем ТВ не проверялись; с Samsung Tizen отчётов пока нет.
